This is the tic-tac-toe implementation using imgui and c++. This program does require cmake to function and build I used the cmake tools extention in VS code to build this project. I needed to do more digging into c++ to learn how to write 2D arrays in this langauges becuase it has been a while and i found that the auto figure is really nice to quickly scan through an array while keeping code clean.

Implmentation 
The game runs in turns of two player placing either a cross or a circle on the grid till one of them can connect three of them making them the winner or the game draws reaching a state where to progress can be made and the game is also transcribed into a given string as it is an easy way to store the game state.
